LIVE STAND SYSTEM
Made by 国分寺美食倶楽部

このドライブは、展示台の映像を保存するための領域です。

【動画の変更方法】
1. 既存の video.mp4 を削除します。
2. 再生したい動画を video.mp4 の名前で保存します。
3. コピー完了後、ドライブを安全に取り外します。
4. PCからUSBケーブルを抜き、通常のUSB電源に接続すると動画が自動再生されます。

【注意事項】
・対応する動画ファイル名は video.mp4 です。
・このReadme.txtは削除しても問題ありません。
・ファイルのコピー中はUSBケーブルを抜かないでください。
・動画ファイルの形式や解像度は初期に入っている video.mp4 に準じてください。
